# ASTERA — план реализации

Локальный проект, без публикации в Sites. Исходное состояние: два референса и оригинальный прозрачный логотип в Branding; кода нет.

## Архитектура
- Vite + TypeScript + Three.js; одна страница, якоря и доступные диалоги подробностей.
- src/data.ts: назначения, флот, опыт, экипаж и демо-тарифы.
- src/planetary.ts: реальные сферы, кольца Сатурна, орбитальное движение, WebGL fallback, остановка вне экрана.
- src/main.ts: десять разделов, меню, детали, демо-поиск, приложение и Privé.
- src/style.css: точные бренд-токены; desktop 1200+, tablet 768–1199, mobile <768.

## Этапы
1. Сохранить идентичность и референсы, подготовить реестр и видеобрифы.
2. Сгенерировать отдельные опорные кадры корабля, интерьера, Сатурна, Луны; затем остальные сцены.
3. Реализовать все десять разделов, настоящую WebGL-карусель и действия кнопок.
4. Оптимизировать локальные изображения в WebP (640/1280), сохранить оригиналы.
5. Проверить TypeScript, lint, build; браузерные проверки desktop/tablet/mobile, ввод и fallback.

## Качество
HTML-текст, нативные формы и dialog, контраст, видимый focus, reduced-motion. DPR ограничен, WebGL загружается отдельным чанком, кадры останавливаются вне viewport. Lazy images ниже первого экрана. Видео только после получения от пользователя, с poster и без звука.

## Разделы
Hero / Destinations / Luxury between worlds / Fleet / Experience / Crew / Booking / Mobile app / Privé / Final CTA + footer.

## Ограничения
Компания и предложения вымышлены. Поиск и выбор маршрута только локальные demo-данные. Никаких платежей, ложных заявок или ссылок на несуществующие приложения. Видео ожидаются от пользователя; сайт работает на статичных постерах.
